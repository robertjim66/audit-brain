审计智脑 · 界面设计系统
DESIGN SYSTEM v2

给建设工程审计人员的专业工具，不该长成一个 Bootstrap 后台

本次改版的目标不是「更好看」，而是「更可信」。面向的人群每天要盯几百页结算书、逐条核对金额、 为每一条结论负责 —— 界面必须传递权威、克制、精确，并且让数字能竖着扫。

01

改了什么，为什么

五处关键改动，每一处都对应一个具体的信任问题，而不是审美偏好。

去掉全部 emoji 图标

导航用 🧭📁⚠️🤖、品牌位是 🔍 —— 这是最致命的一条。审计是出具结论的工作， emoji 会让它看起来像个周末做的个人项目。全部换成 1.6px 线性图标，24 网格、统一视觉重量。

换掉「Bootstrap 蓝」

原来的主色 #0ea5e9 是 Tailwind 默认色，任何人都见过。改成藏青 #1A4C7A —— 政企与审计语境里的权威色，配铜金作证据与 AI 强调色。语义色全部降饱和，去掉荧光感。

1 2 3金额全部等宽数字

审计台面 90% 的信息是数字。默认字体下数字宽度不等，一列金额会歪成锯齿， 根本没法竖着扫。所有金额、工程量、编号统一启用 tabular-nums。

指标卡数字不再染色

原来四个大数字分别是蓝、黄、绿、红 —— 这是仪表盘的廉价感来源。 现在数字统一用主文本色，语义色只出现在左侧 3px 细条上，视线先落在数字，颜色只是辅助。

统一两套视觉体系

项目里原本并存两套颜色：primitives 走设计令牌，但疑点台账、资料舱、 智能问答直接硬编码了 155 处 slate / sky / rose。已全部收编到令牌，深浅色自动一致。

补上专业界面该有的细节

表头吸顶 + 极浅斑马纹（长表格逐行扫读必需）、原生 select 换成自定义下拉、 处置历史改成时间线（契合「留痕」语义）、圆角从 12px 收到 10px（更小的圆角更严肃）。
